# AGENTS.md

{{input.title|xml}} is a resource pack for Minecraft {{resolved.minecraft}}, resource pack format {{resolved.resourcePackFormat}}.{{resolved.resourcePackFormatMinor}}, generated by EMD. There is nothing to build: the folder is the pack.

## Try it

Copy this folder into the game's `resourcepacks/` folder, or zip its contents so `pack.mcmeta` sits at the root of the zip. In the game open Options > Resource Packs and enable the pack. The example below renames the stick, so a stick in the inventory is called "{{input.title|xml}} Stick".

## Layout

- `pack.mcmeta`: the pack's description and the formats it supports.
- `assets/minecraft/lang/en_us.json`: overrides for English text. It renames the stick as an example; delete the entry when you no longer need it.
- Add textures under `assets/minecraft/textures/`, models under `assets/minecraft/models/` and sounds under `assets/minecraft/sounds/`. Files placed at the same path as a vanilla file replace it.

## Rules

- `pack.mcmeta` uses `min_format` and `max_format`. Do not add `pack_format` or `supported_formats`: Minecraft 1.21.9 removed them for packs that only support 1.21.9 and newer.
- Do not edit the format numbers by hand. Ask `emd versions --mc <version>` for the format of a release.
- Resource pack and data pack formats are different numbers. A resource pack uses the resource pack format.
- Names of files and folders under `assets/` use lowercase letters, digits, `_`, `-` and `.` only.
- Every JSON file must be valid JSON. One stray comma stops that file from loading.
