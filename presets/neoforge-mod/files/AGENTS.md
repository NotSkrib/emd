# AGENTS.md

{{input.name}} is a NeoForge mod for Minecraft {{resolved.minecraft}} (NeoForge {{resolved.neoforge}}) on Java {{resolved.java}}, generated by EMD. Minecraft is unobfuscated from 26.1, so there are no mappings to configure.

## Commands

```bash
gradle build              # compile and package build/libs/{{input.modId}}-{{input.version}}.jar
gradle runClient          # start a development client with the mod loaded
gradle runServer          # start a development server with the mod loaded
gradle runData            # run the data generators, writing to src/generated/resources
gradle runGameTestServer  # run the registered game tests, then exit
```

Needs Gradle {{resolved.gradle}} or newer. README.md explains how to get a matching `./gradlew`.

## Layout

- `src/main/java/{{derived.packagePath}}/{{input.name}}.java`: the common entrypoint (`@Mod`).
- `src/main/java/{{derived.packagePath}}/{{input.name}}Client.java`: the client-only entrypoint (`@Mod(dist = Dist.CLIENT)`), never loaded on a dedicated server.
- `src/main/templates/META-INF/neoforge.mods.toml`: the mod descriptor. Dependencies, mixins and access transformers are declared here. The `generateModMetadata` task fills in its version tokens.
- `gradle.properties`: the Minecraft, NeoForge and mod versions.

## Rules

- Code the common entrypoint reaches must never reference client-only classes such as `net.minecraft.client.*`. Client code goes in the client class.
- Register every item, block and entity through a `DeferredRegister` on the mod event bus.
- The mod id `{{input.modId}}` must match in `gradle.properties`, the `MODID` constant, `neoforge.mods.toml` and the `assets/` and `data/` folder names.
- Do not edit `minecraft_version`, `minecraft_version_range` or `neo_version` by hand. Ask `emd versions --mc <version>` and change them together with the Java version.
