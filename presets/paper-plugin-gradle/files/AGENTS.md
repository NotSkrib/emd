# AGENTS.md

{{input.name}} is a Paper plugin for Minecraft {{resolved.minecraft}} on Java {{resolved.java}}, generated by EMD.

## Commands

```bash
gradle build        # compile and package build/libs/{{input.name}}-{{input.version}}.jar
gradle runServer    # start a local Paper server with the plugin loaded (files go in run/)
```

Needs Gradle {{resolved.gradle}} or newer. README.md explains how to get a matching `./gradlew`.

## Layout

- `src/main/java/{{derived.packagePath}}/{{input.name}}.java`: the main class, which extends `JavaPlugin`.
- `src/main/resources/plugin.yml`: the plugin descriptor. Commands and permissions are declared here.
- `build.gradle.kts`: the build. The Paper API version is `{{resolved.paperApi}}`.

## Rules

- Register every command, listener and permission in both the code and `plugin.yml`.
- Never touch worlds, entities or inventories from an async task. Switch back to the main thread first.
- Do not edit the Paper API version or the Java version by hand. Ask `emd versions --mc <version>` and change them together.
