# AGENTS.md

{{input.name}} is a Velocity proxy plugin on Velocity API {{resolved.velocityApi}} and Java {{resolved.velocityJava}}, generated by EMD. It runs on the proxy, not on a backend server.

## Commands

```bash
gradle build          # compile and package build/libs/{{input.name}}-{{input.version}}.jar
gradle runVelocity    # start a local Velocity proxy with the plugin loaded (files go in run/)
```

Needs Gradle {{resolved.gradle}} or newer. README.md explains how to get a matching `./gradlew`.

## Layout

- `src/main/java/{{derived.packagePath}}/{{input.name}}.java`: the main class. Velocity builds it with Guice, so it needs the `@Inject` constructor.
- `src/main/resources/velocity-plugin.json`: the plugin descriptor. The `id` and `main` fields must match the code.
- `build.gradle.kts`: the build. The Velocity API version is `{{resolved.velocityApi}}`.

## Rules

- Handle events with `@Subscribe` methods on the main class or on a listener registered through the event manager.
- Never block an event handler. Move slow work, such as network and disk access, to `server.getScheduler()`.
- Do not edit the Velocity API version or the Java version by hand. Ask `emd versions` and change them together: the API declares the Java version it was compiled for.
