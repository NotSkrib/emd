# AGENTS.md

{{input.name}} is a Fabric mod for Minecraft {{resolved.minecraft}} on Java {{resolved.java}}, generated by EMD. Minecraft is unobfuscated from 26.1, so there are no mappings to configure.

## Commands

```bash
gradle build        # compile and package build/libs/{{input.modId}}-{{input.version}}.jar
gradle runClient    # start a development client with the mod loaded
gradle runServer    # start a development server with the mod loaded
```

Run `gradle wrapper` once if you want `./gradlew`.

## Layout

- `src/main/java/{{derived.packagePath}}/{{input.name}}.java`: the common entrypoint (`ModInitializer`).
- `src/client/java/{{derived.packagePath}}/client/{{input.name}}Client.java`: the client-only entrypoint.
- `src/main/resources/fabric.mod.json`: the mod descriptor. Mixins, access wideners and dependencies are declared here.
- `gradle.properties`: the Minecraft, Fabric Loader, Fabric Loom and Fabric API versions.

## Rules

- Code in `src/main` must never reference classes from `src/client`. Client-only code goes in `src/client`.
- Do not edit the version lines in `gradle.properties` by hand. Ask `emd versions --mc <version>` and change them together with the Java version.
- Register every item, block and entity in its registry during `onInitialize`.
