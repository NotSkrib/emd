# AGENTS.md

{{input.title|xml}} is a data pack for Minecraft {{resolved.minecraft}}, data pack format {{resolved.dataPackFormat}}.{{resolved.dataPackFormatMinor}}, generated by EMD. There is nothing to build: the folder is the pack.

## Try it

Copy this folder into a world's `datapacks/` folder, or zip its contents so `pack.mcmeta` sits at the root of the zip. In the game run `/reload`, then `/datapack list` should show the pack, and chat shows "{{input.title|xml}} loaded".

## Layout

- `pack.mcmeta`: the pack's description and the formats it supports.
- `data/{{input.name}}/function/`: this pack's functions, called as `{{input.name}}:<path>`.
- `data/minecraft/tags/function/load.json`: runs `{{input.name}}:load` when the world loads and on every reload. Add `tick.json` next to it to run a function every tick.

## Rules

- Folder names are singular since Minecraft 1.21: `function`, `advancement`, `recipe`, `loot_table`, `predicate`, `structure`, and `tags/item`, `tags/block`, `tags/function`. The old plural names (`functions`, `recipes`, `loot_tables`) were renamed away and are not read.
- `pack.mcmeta` uses `min_format` and `max_format`. Do not add `pack_format` or `supported_formats`: Minecraft 1.21.9 removed them for packs that only support 1.21.9 and newer.
- Do not edit the format numbers by hand. Ask `emd versions --mc <version>` for the format of a release.
- Put everything of this pack under `data/{{input.name}}/`. Under `data/minecraft/` add only tags that extend vanilla ones.
- Function files hold one command per line, written without a leading slash. A line that starts with `#` is a comment.
